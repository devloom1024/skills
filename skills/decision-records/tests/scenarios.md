# 决策治理行为场景

独立执行者只看用户请求、Skill及目标项目原始材料，不看此验收表。所有产物在隔离目录，语义结论必须依据真实输入。

| 场景 | 可观察要求 |
|---|---|
| 入口存在但全提案未完成 | 提案保持活动且说明缺口，不凭函数存在标implemented |
| 新存储部分取代旧决定 | 保留旧的失败保证、尚未迁移消费者和理由，明确新旧范围 |
| 已移除的历史能力 | 语义判断先于封存，字节保持，仅插日期；活动引用标历史 |
| 首次封存无基准 | 当前一致性可通过，protected_entries=0且不冒称历史保护 |
| 已封存内容改变 | verify失败，不自动重封或更新旧hash掩盖异常 |
| 当前清单也被改写 | GitHEAD或先前可信快照比较失败，阻止seal |
| 第二次只读审查 | 不改文件、不再归档同一记录，不建立重复清单 |
| 仅安装本Skill | 能按目标约定完成任务，不依赖project-docs资源路径 |
| 既有ADR格式 | 保留accepted含义与编号，不强制转换头部；不支持封存时报告适配缺口 |
| 与project-docs协作 | 两者读同一目标约定，初始化不捏造已集成工具，治理不覆盖已有规则 |

CLI测试另以真实临时目录验证改/删/移/重排、无基准追加拒绝、锁、路径与写入回滚。语义、链接和实施证据仍需独立核对。
