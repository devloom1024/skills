# 文档标准

## 事实归属

根 AGENTS 保存全仓常驻约束和导航；局部 AGENTS 只补充局部规则；架构说明模块协作；子系统参考说明跨模块语义；模块 README 说明使用、配置和限制；Cookbook 给出操作与验证；决策记录解释长期选择；Postmortem 记录事故；LESSONS 保存经验与正式规则去向。

每项事实只有一个维护位置，其他地方引用。上层解释自己和直接子层的职责，不复制下层细节。目录随实际信息增长，不创建无用空壳。

## 内容要求

明确读者和查询问题，覆盖适用的输入输出、条件、默认值、失败、生命周期、所有权、兼容和限制。教程按前提与步骤通向可观察结果；参考按主题描述当前行为；历史与提案不冒充现状。

命令、路径、字段和默认值核对源码与配置，操作说明尽可能实际执行；未验证项单独报告。删掉推理过程和代码复述，保留必要契约与上下文。文档中代码示例和真实可执行步骤应区分。

## 同步与验证

职责、接口、状态、失败或兼容保证变化时同步所属文档；机械或内部改动只修受影响事实和链接。迁移后修复入站引用。决策完成时同步路径、状态和当前正文，归档只用于历史。

常驻文档超限先迁移错位内容，再压缩；必要内容确需空间时说明理由调整。格式检查不能证明语义正确，交付报告区分机械检查、源码核对和实际运行证据。
