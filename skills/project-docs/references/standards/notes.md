# Agent Notes 接入

## 职责与协议

Notes 保存**决定理由、真实备选方案与代价**；当前行为、接口与操作步骤归 [docs 与模块参考](docs/README.md)，待办和聊天过程不自动成为决定。

**唯一协议来源是 [write-notes-like-deepseek](https://github.com/czm15053/write-notes-like-deepseek/tree/main/skills/write-notes-like-deepseek)。** 创建条件、格式、分类、生命周期与校验均读实际安装版本；本 Skill 不另建模板或脚本。旧定义冲突时迁移到外部协议；用户要求和生效项目指令优先。既有 ADR 按外部适配规则处理，不自行重编号。不默认引入看板、额外审批或重复确认已授权事项。

## 探测与安装

1. 在当前 Skill 列表、项目和全局目录查找当前 agent **实际可读取的 `SKILL.md`**。已有则复用，不擅自升级；登记或网页可访问不代表已安装。
2. 缺失时询问用户选择**项目安装、全局安装或暂不安装**，已有明确选择直接沿用；未回复不默认选择。项目范围仅当前仓库，全局范围供当前用户跨项目使用。
3. 选择后在项目根运行下方命令，完成同一次安装不再询问。随后定位并读取安装文件及相关参考，确认运行环境、Notes 路径与校验命令。

### 自动安装命令

将 `<agent-id>` 换成当前 agent 的 CLI 标识（Codex 为 `codex`），仅安装指定 Skill：

```sh
npx --yes skills add czm15053/write-notes-like-deepseek --skill write-notes-like-deepseek --agent <agent-id> --yes
```

全局安装在同一命令末尾加 `--global`。参数见 [skills CLI](https://github.com/vercel-labs/skills/blob/main/docs/commands.md#skills-add)。

Node.js/npx 缺失或安装失败时报告实际原因，不自动改换范围或安装系统工具链。用户暂不安装时继续可独立完成的 AGENTS/docs 工作，明确 Notes 接入未完成，不生成替代协议；仅要求方案或草稿时不执行安装。

## 项目接入与维护

- **记录来源和入口**：在项目已有文档所有者记录来源、实际版本或修订、安装范围与方式、Skill 路径和真实校验命令；无版本时记录读取日期。使用项目可移植路径，不写作者本机绝对路径。
- **接通检索**：根或适用子树 AGENTS 写调用时机与检索入口；修改前按模块、机制检索活动决定。当前参考链接理由 Note，Note 链接对应参考、实现与验证入口；已有源码提示随路径同步，不机械铺设注释。
- **同步理由**：事实变化按外部流程更新相关 Note；保留真实依据、独特后果和验证缺口，不从最终代码虚构历史讨论。
- **落实检查**：安装不等于配置了命令或 CI。按外部协议接入并运行实际工具；Skill 安装目录从普通文档检查中排除，Notes 单独校验。

交付说明外部依赖、接入入口、实际检查与未完成项。依赖、格式适配或验证工具未落实时，不称 Notes 治理完成；结构和冻结检查通过也不代表语义已验证。
