# 测试与验证文档

## 职责

`docs/testing.md` 解释项目如何验证行为：测试层级、适用策略、隔离要求，以及本地与 CI 的责任分工。

## 内容与组织

按项目真实机制说明各层检查的对象、保证与局限、命令入口、构建或生成前提、所需环境，以及成功、失败和跳过的含义。

建立有依据的「改什么 → 检查什么」选择方法；明确平台、凭据和昂贵检查的触发条件。已有测试要求不能因当前环境不便而静默放宽，缺失检查如实说明，不编造命令。

解释保证验证有效的项目要求，例如真实入口、替身范围、夹具隔离和资源清理；**只收录项目已采纳的政策**，不照搬外部覆盖率、平台或真实 API 要求。

具体夹具、采集方式和测试机制放在最低合适的测试目录或模块参考，公共文档链接过去，不列全库用例。覆盖率不等于行为正确，跳过不等于通过；实际结果报告遵循文档总则。

## 同步

验证入口、层级、策略、环境或结果解释变化时更新；测试政策的长期取舍链接 Note，临时运行结果留在交付证据。
