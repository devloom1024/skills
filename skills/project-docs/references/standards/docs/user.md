# 产品使用文档

## 职责

`docs/user/` 服务产品消费者，包括适用的管理员和扩展开发者，帮助他们使用已提供的能力。仓库贡献流程归 development 或 Cookbook，不要求读者先理解源码结构。

## 内容与组织

以读者目标组织导航，**区分起步、具体任务与查询参考**：起步给一条首次成功路径，任务页说明操作与结果，参考页按配置或功能主题解释用法和限制。

说明影响操作的版本、部署、权限和平台前提；在选择前交代费用、副作用及数据后果。常见失败给出识别与恢复办法，使用产品术语，不堆内部实现概念。

界面、命令、配置与截图须对应当前产品，不能将设计稿或设想写成已提供能力。任务相关资源靠近正文，产品变化时一起维护。

通过 README 或实际网站 index 按前提导航，独立主题群再分目录。项目 README 帮助选择与进入产品，用户文档承接具体任务或查询，不重复维护相同操作正文。网站发布视图复用这些来源。

## 同步

产品能力、界面、操作、安装或权限变化时更新相应页面和资源，保持用户入口、路由与正文一致。
