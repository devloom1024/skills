# 开发文档

## 职责

`docs/development.md` 帮助贡献者建立开发环境，找到日常启动、构建和检查入口，并理解 CI 的主要职责。

## 内容与组织

**将首次准备与日常参考分开**：

- 准备教程：实际工具与版本、依赖和环境配置、首次启动或构建，以及可观察成功结果。
- 日常参考：开发命令、构建输出、适用平台差异、环境变量及 CI 概览。

版本以运行时声明、manifest、锁文件和 CI 等实际配置核对；存在冲突先查明。命令说明必要工作目录、前提和用途，链接真实脚本，不另维护易漂移的逐项 CI 清单。凭据只说明变量和获取前提，示例不含秘密。

公共环境只说明一次，模块特有准备步骤链接模块参考。测试策略链接 testing，详细贡献任务链接 Cookbook，工程要求链接适用规范，工具选择理由链接 Note。

## 同步

环境、工具版本、启动、构建或 CI 入口变化时更新。首次准备路径应能到达工作环境，后续开发和验证入口清楚。
