# 模块参考

## 职责

模块 `README.md` 靠近源码，帮助消费者选择和使用模块，也帮助维护者理解必要设计。模块可以是包、服务、应用或独立维护单元，不要求每个目录都有 README。

## 内容与组织

按读者需要**从使用递进到设计**，通常包括以下内容；按模块类型取舍，不机械生成章节：

1. 用途：能做什么、何时选用、主要限制。
2. 基本使用：真实入口、最小配置或调用示例，以及可观察结果。
3. 高级使用：影响选择的配置、输入输出语义、副作用及操作限制。
4. 必要设计：主要组成、数据流、生命周期和扩展点，并链接源码细节。
5. 已知限制与相关参考：真实缺口、适用条件及进一步阅读入口。

开头用少量文字说明能力，避免先堆内部身份和注册项。复杂页面提供目录；较重的实现说明可分节或折叠，不影响常用信息查询。

配置只解释本模块拥有的字段；单位、默认值、生效阶段及失败后果按实际写明。已有 JSDoc、子系统类型或生成目录时链接其来源，不复制逐函数或事件清单，也不叙述其他模块内部实现。

安装与启动方式依据实际模块类型；库不套用应用启动步骤。模型相关模块按需要说明模型可见内容、token 与缓存影响，普通模块不增设此类章节。限制描述已知事实，不以愿望清单补齐版式。

## 同步

使用、配置、行为、设计或限制变化时同次更新。跨模块语义仍由子系统参考拥有，长期取舍链接 Note。
