# 架构参考

## 职责

`docs/architecture.md` 是**系统有序图谱**，解释组成、整体运行与扩展位置，帮助维护者判断新行为放在哪里、影响哪些部分。

## 内容与组织

按理解顺序介绍核心组成与职责、依赖方向和运行入口，再说明关键请求或数据如何跨组件流动，以及已有扩展点。进程、部署、持久化和安全约束只展开影响整体协作的部分。

图与文字描述同一现状。以实际入口和消费者核对路径，不按目录名称猜架构，不加入实现进度或未来组件。

类型与接口语义链接子系统，模块使用和配置链接模块 README，设计理由链接 Note。只展示理解整体所需的模块地图，不复制源码或生成器已有的完整清单。

默认一份总览；独立架构主题确需分拆时保留总览及明确入口，不逐源码目录生成架构页。

## 同步

组成、依赖、整体运行、扩展方式或全局约束变化时更新；局部实现细节由所属参考维护。
