# Cookbook

## 职责

`docs/cookbook/` 是贡献者操作教程，**一篇完成一个实现、集成或维护任务**。面向产品消费者的操作归 user，接口语义链接参考，设计理由链接 Note。

## 内容与组织

开头写清目标、读者起点、必要前提与适用范围，再按依赖顺序列编号步骤：

1. 给出实际需要的命令、配置或文件修改。
2. 在关键步骤注明验证方法与预期结果。
3. 说明会影响后续操作的常见失败、恢复或清理方式。
4. 以最终目标的验证收尾，而非只确认命令返回零。

先提供最短成功路径，进阶内容另节展开。示意代码与完整可运行示例明确区分；创建文件需说明有效内容，修改配置需说明消费者及生效方式。

文件名使用动作与对象，如 `add-provider.md`。默认平铺；多个任务用 README 按目标和前提导航，独立任务群再分组。已有同义教程时更新原文，不新建竞争版本。

## 同步

操作入口、配置、步骤、输出或恢复方式变化时同步正文、样例与资源；实际执行记录不进入长期教程。
