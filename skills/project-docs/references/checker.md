# 机械检查器

## 调用与结果

Python 3.10+，仅标准库。相对 `--config` 路径以目标项目根目录为基准；不自动搜索配置，避免不同机器隐式使用不同规则。

```text
python <skill-dir>/scripts/check_docs.py <project-root>
python <skill-dir>/scripts/check_docs.py <project-root> --config docs/doc-rules.json --json
```

退出码：0 表示覆盖的规则无错误，可以仍有提示；1 表示文档错误；2 表示配置、读取或运行条件错误。JSON 包含 `scope`、`findings`、`summary`；问题含 severity、code、path、line、message。路径行号为 1 起算；文件级问题 line 为 0。

报告必须说明覆盖范围，不能把通过说成文档语义已验证。

## 配置

没有配置时要求 `AGENTS.md` 和 `docs/AGENTS.md`，检查根目录下符合条件的 Markdown，决策默认位于 `.agents/notes`。`required_files` 声明实际采用的必要入口，不能为了通过检查把丢失的必需入口删掉。

```json
{
  "required_files": ["AGENTS.md", "docs/AGENTS.md"],
  "exclude": ["fixtures/**"],
  "note_roots": [
    {"path": ".agents/notes", "format": "agent-note"},
    {"path": "docs/adr", "format": "external"}
  ],
  "budgets": {
    "AGENTS.md": {"metric": "mixed", "max": 1600},
    "docs/AGENTS.md": {"metric": "mixed", "max": 2200}
  }
}
```

数字是一个配置示例，不是全项目统一阈值。字段语义：

- `required_files`：项目相对文件路径；提供时替代默认列表。单条决策维护等局部任务可声明本次实际需要的入口，不能借局部配置宣称全仓采用已完成。
- `exclude`：项目相对路径的、区分大小写的 fnmatch 模式；`drafts/**` 排除整个 drafts 目录。只用于不属于维护范围的生成/样本内容。
- `note_roots`：不重叠的决策根目录，提供时替代默认列表。`agent-note` 检查规范格式；`external` 保留现有格式，仍检查链接等通用规则，并给人工核验提示。
- `budgets`：按具体 Markdown 文件指定预算，路径必须为规范相对路径（不含 `./`、重复斜线或父级跳转）；没有声明就不执行篇幅硬限制。预算文件不存在报错，必要/预算文件自身或祖先目录被排除视为无效配置；显式要求的文件未进入扫描集也不能成功。
- `words` 统计全文空白分隔词；`mixed` 统计全文中每个 CJK（汉字/假名/韩文）字符加其余字母数字词。代码与表格也占上下文，纳入计量。

默认排除所有层级的 `.git`、`.cache`、`node_modules`、`vendor`、`.venv`、`venv`、`__pycache__`、`dist`、`build`、`target`、`coverage`、`.generated`。若项目手工文档恰在同名目录，应先调整该约定或使用项目自己的检查器，不能声称这些文件已覆盖。

## 已覆盖

- 必要文件存在、有效扫描集不为空、读取错误不冒充成功。
- Markdown 行内链接、图片和已定义引用式链接的本地文件目标，包括百分号编码、标题和常见括号路径。
- 屏蔽代码围栏、行内代码、缩进代码和 HTML 注释，避免把示例当实际引用或占位内容。
- 本地链接不能越出项目根；文件符号链接目标不能越出根；不遍历符号链接或 junction 目录。
- prose 中未填模板标记 `{{…}}`、独立的 `TODO` / `TBD`、`待填写`；代码示例中相同字样不作为草稿。
- Agent Note 的类别、有效日期文件名、头部、状态、必要章节、空章节、已实施记录残留提案章节。
- archive 的状态和归档日期；跳过历史正文的链接与占位检查，仍执行显式预算；引用归档时提示确认历史用途。
- 显式配置的全文预算。

## 未覆盖与人工检查

不解析完整 CommonMark/MDX，不验证锚点、外部 URL、动态路由、HTML 内链接、脚注和复杂内嵌语法；图片仅检查目标存在，不检查视觉呈现。省略标签的 shortcut 只有标签定义存在时才识别为引用，普通方括号不猜成坏链接。目录分类、命名是否合适、页面可发现性、索引完整性与拆分合理性由人工对照目录契约检查；本版不强制固定目录或自动生成索引。

不执行文档命令、不联网、不读取源码来证明语义、不确认替代方案或事故证据真实性、不冻结校验归档内容历史。archive 引用提示不会判断引用是否真被用作当前权威。配置映射为 external 的 ADR 结构与状态需要人工核对。

冻结完整性由目标项目已有工具或独立 decision-records 工具验证，不能以本脚本通过替代。两类工具各报告真实范围，均以目标项目实际记录规范为准；本脚本无需另一个 Skill 安装。

中文/英文规范章节均支持，额外文档语言、已知不同模板及双语副本需要显式适配，不能靠排除真实内容宣称等价。若要接入项目现有 Markdown 工具，先对照以上范围，避免两套校验规则冲突。

只读实现不创建缓存、配置或报告文件；需要保存 JSON 时由调用方选择目标路径。扫描排除列表会出现在报告中，目录符号链接不在扫描语料内。
